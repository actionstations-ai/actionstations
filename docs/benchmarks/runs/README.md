# Submitted benchmark runs

One JSON file per model and machine, as `pnpm bench` writes it
(`<date>-<model>-<machine>.json`). Add yours by pull request, then run `pnpm bench:report`
and commit the updated `../model-benchmarks.json` and `../README.md` with it. See
[Benchmarking local models](../../guides/model-benchmark.md).
