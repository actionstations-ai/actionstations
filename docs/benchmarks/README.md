# Local model benchmarks

How well free local models (LM Studio, Ollama) do the work Action Stations asks of them:
ideation, MSEL drafting and critique, scored on the shipped example corpora with the app's own
checks. Every number comes from a run on a contributor's computer; no cloud model and no cloud
judge are involved.

- `model-benchmarks.json`: the merged report the website reads (schema:
  `model-benchmarks.schema.json`).
- `runs/`: the submitted run files, one per model and machine.
- How to run the benchmark and submit a run:
  [Benchmarking local models](../guides/model-benchmark.md).

Scores are 0 to 100. A memory tier's recommendation is the best model that fits the smallest
machine in the tier (size on disk plus an estimate of the context cache) and passes the floor:
every task at least 50, drafting reliability at least 90%, and stable across repeats.
