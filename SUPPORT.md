## Bugs and feature requests

Open a GitHub issue on `actionstations-ai/actionstations` from one of the templates (bug, feature, new inject type). For a bug, include:

- the app version and operating system;
- the provider and model involved, if generation is part of it;
- what you did, what you expected and what happened;
- the log, if there is one. Logs never hold API keys, but check them for your own document text before you attach them.

Search the existing issues first; a thumbs-up on an existing issue helps more than a duplicate.

## Security problems

Never in a public issue. Follow [SECURITY.md](SECURITY.md) and email the report.

Action Stations is maintained by a small team. Issues are triaged as time allows, usually within a week. There is no paid support channel.
