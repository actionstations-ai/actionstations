# Epidemiology toolkit

Included with Action Stations. A toolkit any scenario can turn on, whatever the organization: a health department, a hospital, a school district, an airport, a cruise port or a food processor.

## What it adds

- Seven inject templates: case report form, outbreak questionnaire, public exposure notice, clinician health alert, school or employer letter, isolation and quarantine guidance, hotline call notes. It also uses the laboratory result report, situation report and press release already in the app.
- Writing guidance: case definition tiers, onset date rather than report date, exposure window arithmetic, attack rate and odds ratio, the ten investigation steps, and response facts for norovirus, Salmonella, measles, influenza, SARS-CoV-2, pertussis and Legionella, each with its source.
- Nine structured decisions: adopt a case definition, declare an outbreak, request Epi-Aid, classify a contact, issue an exposure notice, recommend exclusion or closure, set laboratory priority, open or close a dispensing site, release data.
- Evaluation measures named by id: time from first report to case definition, declaration, first control measure and public notice; message consistency; contact reach; dispensing throughput; curve accuracy.

## Limits

Response facts are for public health decisions, not clinical care, and carry no pathogen handling detail. Pathogen values are teaching values with sources; a state or local epidemiologist and an infection preventionist should review them before use. Every person and place is fictional.
