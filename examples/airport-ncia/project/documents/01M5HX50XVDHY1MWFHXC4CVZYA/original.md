# NCIA Terminal Map

The original `NCIA Terminal Map.pdf` is image-only (no extractable text) and must be copied into `reference/originals/`. It is the base image for the `map_annotation` inject type and for the Player Briefing's "Map Sketch" page.

Known layout facts from the AEP/TIRP/ASP (use to validate generated injects):

- Two-level terminal: Level 1 Arrivals/Baggage Claim; Level 2 Ticketing/Departures.
- 18 gates on the Main Terminal Ramp: **A1–A8** (Concourse A, Skyline/HWK Air) and **B1–B10** (Concourse B). *(Scenario 3 deliberately references non-existent Gate C4 and Gate Z99 as data-integrity tells.)*
- Shelters: A (Level 1 restrooms/corridors), B (Concourse A stairwells A3/A4), C (Concourse B restrooms, stairwells B1/B2); Level 2 Ticketing is to be avoided.
- Public Assembly Point: Rideshare Pickup Area (West End). Employee Assembly Point: Employee Parking Lot C (North).
- AOC: Terminal Ground Level, Room 104. EOC: Administration Building, 3rd Floor. Backup EOC: ARFF Station 9 Training Room.
- Runways 5/23 (primary, 10,001 ft) and 1/19 (crosswind, 7,600 ft); Taxiways A–D; North Cargo Ramp; GA Ramp (southeast, Gate 24); Fuel Farm (northeast); ARFF mid-field.
- Access via Airport Boulevard from I-77 Exit 122.
