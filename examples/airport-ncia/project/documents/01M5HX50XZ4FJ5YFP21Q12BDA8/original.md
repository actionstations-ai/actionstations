# ICS 203 — Organization Assignment List (FEMA)

Source: https://training.fema.gov/icsresource/icsforms.aspx (public domain). Original PDF ("ICS Form 203 – Organization Assignment List v3.pdf") goes in `reference/originals/`. Basis for the optional `ics_203_prefill` template.

## Blocks
1. Incident Name · 2. Operational Period (Date/Time From – To)
3. **Incident Commander(s) and Command Staff:** IC/UCs, Deputy, Safety Officer, Public Info. Officer, Liaison Officer
4. **Agency/Organization Representatives:** Agency/Organization | Name
5. **Planning Section:** Chief, Deputy, Resources Unit, Situation Unit, Documentation Unit, Demobilization Unit, Technical Specialists
6. **Logistics Section:** Chief, Deputy; Support Branch (Director, Supply Unit, Facilities Unit, Ground Support Unit); Service Branch (Director, Communications Unit, Medical Unit, Food Unit)
7. **Operations Section:** Chief, Deputy, Staging Area; Branches (Director, Deputy, Divisions/Groups); Air Operations Branch (Director)
8. **Finance/Administration Section:** Chief, Deputy, Time Unit, Procurement Unit, Comp/Claims Unit, Cost Unit
9. Prepared by: Name · Position/Title · Signature · Date/Time · IAP Page ___

## Purpose
Lists activated units and the personnel staffing each position; used to complete the Incident Organization Chart (ICS 207). Prepared by the Resources Unit under the Planning Section Chief; attached to ICS 202 as part of the IAP. Not all positions need to be filled; trainees marked "(T)"; multiple names separated by a slash; add pages as needed.
