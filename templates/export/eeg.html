How to use these guides

  • One guide per Core Capability the exercise objectives exercise ({{intro.count}} in all). Each critical task is an action the organization's own plan requires; the Source column names the section.
  • Observation Keys name the MSEL injects where the task should be seen. Rate each task M (met), P (partially met), N (not met) or NO (not observed) and note what you saw.
  • Ratings describe how the plan was followed, not how a person performed. Notes go to the hot wash and the after-action report; do not name players.
